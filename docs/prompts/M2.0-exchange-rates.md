# M2.0 — Exchange Rates Feature Prompt

## Milestone

**M2.0 — Exchange Rates**

## Objective

Implement the first complete business feature: retrieve current exchange rates from the Polish National Bank (NBP) public API through the Spring Boot backend and display them in the Angular frontend.

## Scope

Full vertical slice implementation with no database, authentication, caching, or persistence.

Returns a list of exchange rates.
The endpoint must not expose the raw NBP response.

NBP Client: Use RestClient (not RestTemplate). Configure as Spring Bean.
Base URL: https://api.nbp.pl
Endpoint: /api/exchangerates/tables/A?format=json

External DTOs: NbpTableDto, NbpRateDto — only for NBP communication.

Service: Call client, validate, convert via MapStruct, return internal DTOs.
Controller: Expose endpoint, return HTTP 200, delegate to service.

Error Handling: If NBP API unavailable, return controlled exception via GlobalExceptionHandler.

## Result

All items in the Definition of Done were satisfied:

- Backend: `mvn clean verify` — BUILD SUCCESS
- Frontend: `npm run build -- --configuration development` — bundle generation complete
- `GET /api/exchange-rates` implemented and integrated end-to-end
- External DTOs (`NbpTableDto`, `NbpRateDto`) strictly isolated from internal DTOs (`ExchangeRateResponse`, `ExchangeRateDto`)
- MapStruct `ExchangeRateMapper` performs all conversions declaratively
- `RestClient` used; `RestTemplate` not used
- Angular `ExchangeRateService` delegates to existing `ApiService`
- All four UI states (loading, success, empty, error) implemented with Angular Signals
- Documentation updated
